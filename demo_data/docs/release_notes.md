# Nimbus Notes Release Notes

## Version 2.3 (released 12 August 2026)

- Offline mode: notes can be read and edited without an internet connection on desktop and
  mobile. Changes sync automatically when the device is back online.
- Faster search: full-text search is now up to 3x faster in large workspaces.
- New "Focus mode" that hides the sidebar and toolbars while writing.

## Version 2.2 (released 3 May 2026)

- Dark mode for all desktop and mobile apps.
- Templates gallery with 40 ready-made templates for meeting notes, project plans and more.
- Bug fix: images pasted from the clipboard no longer lose their original resolution.

## Version 2.1 (released 15 January 2026)

- Real-time collaboration for up to 50 simultaneous editors per note.
- Comments and @mentions inside notes.

## Version 2.0 (released 1 October 2025)

- Completely redesigned editor with Markdown shortcuts.
- Public REST API v2 released.

## Deprecations

- The legacy REST API v1 will be shut down on 31 December 2026. All integrations must migrate
  to API v2 before that date.
- Support for Windows 8.1 ended with version 2.2.
